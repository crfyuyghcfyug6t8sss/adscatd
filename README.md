# my-ads.cards

موقع PHP لإصدار بطاقات Visa و Mastercard للإعلانات الممولة والمدفوعات الرقمية.

## التشغيل

يحتاج: PHP 8.1+ مع امتداد `pdo_sqlite`.

```bash
php -S 0.0.0.0:8080 -t .
```

ثم افتح: `http://localhost:8080`

عند أول تشغيل يتم إنشاء قاعدة البيانات في `data/rozana.db` وحساب الأدمن الافتراضي:

- الهاتف: `0968874525`
- كلمة السر: `Yazenstars1`

> غيّر كلمة السر فوراً من قسم المستخدمين بعد الدخول.

## البنية

- `index.php` — الصفحة الرئيسية
- `register.php` / `login.php` / `logout.php` — حسابات
- `dashboard.php` — لوحة المستخدم
- `wallet.php` — محفظتي + طلبات الإيداع اليدوي
- `apply.php` — تقديم طلب بطاقة (Visa أو Mastercard) مع خصم تلقائي من المحفظة
- `cards.php` — بطاقاتي + إشعارات OTP/3DS
- `charge.php` — طلب شحن بطاقة (أول شحن بدون عمولة)
- `admin/` — لوحة الإدارة (طلبات، بطاقات، طلبات شحن، إيداعات محفظة، مستخدمون، طرق دفع، إشعارات، إعدادات)
- `includes/` — bootstrap (DB, auth, helpers, layout)
- `assets/` — CSS و JS

## التدفق

1. المستخدم يسجل برقمه وكلمة السر فقط.
2. يشحن محفظته من **محفظتي** عبر طرق الدفع اليدوية.
3. الإدارة توافق على الإيداع → الرصيد يُضاف للمحفظة.
4. المستخدم يطلب بطاقة (يختار Visa أو Mastercard، يحدد قيمة الشحن).
5. يتم خصم: قيمة الشحن + رسوم الإصدار من المحفظة فوراً.
6. الإدارة توافق → تظهر البطاقة. أو ترفض → يُعاد الرصيد للمحفظة.
7. المستخدم يطلب شحن البطاقة (أول شحن بدون عمولة، البقية بنسبة محددة).
